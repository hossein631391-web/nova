# وب‌سایت انجمن نجوم و فناوری‌های فضایی NOVA

سایت ایستا و چندصفحه‌ای؛ بدون سرور و بدون مرحلهٔ build. فقط HTML، CSS و JavaScript.

## ساختار

| مسیر | توضیح |
|---|---|
| `index.html` | صفحه اصلی و هیرو |
| `about.html` | درباره ما و عضویت |
| `events.html` | رویدادها و رصدها (فیلتر آینده / گذشته) |
| `news.html` | اخبار و مقالات (فیلتر دسته‌بندی و نمای جزئیات مقاله) |
| `gallery.html` | گالری آسمان با لایت‌باکس |
| `videos.html` | ویدیوهای انجمن (یوتیوب) |
| `admins.html` | مدیران انجمن |
| `assets/css/style.css` | استایل مشترک و تم‌ها |
| `assets/js/stars.js` | پس‌زمینه ستاره‌ها با جذب به نشانگر |
| `assets/js/main.js` | تم، هدر، فوتر، منوی موبایل، انیمیشن ورود |
| `assets/images/` | تصاویر سایت |
| `data/*.js` | داده‌های رویدادها، مقالات، گالری، ویدیوها و مدیران |
| `.nojekyll` | اجازه می‌دهد GitHub Pages فایل‌ها را بدون پردازش Jekyll منتشر کند |

## ویرایش محتوا

تمام محتوای قابل تغییر در پوشهٔ `data/` است. مثلاً برای افزودن رویداد، یک آبجکت جدید به `window.NOVA_EVENTS` در `data/events.js` اضافه کنید.

- **رویدادها:** `date` را به‌صورت میلادی `YYYY-MM-DD` بنویسید؛ سایت خودش تشخیص می‌دهد آینده است یا گذشته.
- **ویدیوها:** شناسهٔ یوتیوب را در `youtubeId` بگذارید. تا وقتی `REPLACE-ME` باشد، کارت جای‌نگهدار نشان داده می‌شود.
- **گالری:** فایل عکس را در `assets/images/` بگذارید و `src` را مثلاً `"assets/images/sky-01.jpg"` بنویسید.
- **مدیران:** عکس را در `assets/images/` بگذارید و `photo` را تنظیم کنید؛ در غیر این صورت حروف اول نام نمایش داده می‌شود.

تمام متن‌های فعلی نمونه‌اند و باید با اطلاعات واقعی انجمن جایگزین شوند.

## انتشار روی GitHub Pages

1. یک مخزن جدید در GitHub بسازید (مثلاً `nova-website`).
2. تمام فایل‌ها و پوشه‌ها را (شامل `.nojekyll`) به ریشهٔ مخزن آپلود یا push کنید.
3. در مخزن به **Settings → Pages** بروید.
4. در بخش **Build and deployment** گزینهٔ **Source** را روی **Deploy from a branch** بگذارید.
5. شاخهٔ **main** و پوشهٔ **/ (root)** را انتخاب کنید و **Save** بزنید.
6. چند دقیقه صبر کنید؛ آدرس سایت به شکل `https://username.github.io/nova-website/` نمایش داده می‌شود.

> همهٔ مسیرها نسبی هستند، بنابراین سایت زیر آدرس `username.github.io/repo-name/` بدون مشکل کار می‌کند.

## نکات

- فونت‌ها از Google Fonts (Vazirmatn و Orbitron) بارگذاری می‌شوند؛ برای استفادهٔ آفلاین فایل‌های فونت را در `assets/` قرار دهید.
- اگر کاربر حرکت کم را در تنظیمات سیستم فعال کرده باشد، ستاره‌ها و انیمیشن‌ها غیرفعال می‌شوند.
- رنگ‌ها در `assets/css/style.css` و در بخش `:root` (تم تاریک) و `[data-theme="light"]` (تم روشن) تعریف شده‌اند.
